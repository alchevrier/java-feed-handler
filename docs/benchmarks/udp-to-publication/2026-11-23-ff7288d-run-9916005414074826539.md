ingress drops, full book rings, or stale runs. The reference steady run
applied 1,023.8 updates/s; the other three applied 1,024.0 updates/s.

Both boundaries end at successful snapshot publication. The send
boundary starts at the first UDP send attempt; the deadline boundary
also includes sender delay. Send-to-publication p99 differed by less
than 20 microseconds between books in both workloads. The packed steady
run had a higher p99.9, but one sample set per case does not establish a
book regression or identify the cause. The trace holds at most one live
order, includes snapshot construction with each book's quote read path,
and does not isolate book mutation costs or measure physical NIC latency.
